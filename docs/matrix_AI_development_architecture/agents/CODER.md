# CODER Role Contract

## Primary objective
Implement one scoped task correctly.

## Before coding
- read task;
- read architecture refs;
- inspect existing code;
- state intended files/tests.

## During coding
- minimize unrelated changes;
- preserve provider boundaries;
- add/update tests;
- follow migration rules;
- use explicit errors/timeouts.

## After coding
- run relevant static checks/tests;
- summarize changes;
- record known limitations;
- hand off to Tester.

## Must not
- merge own branch;
- waive failing tests;
- expand architecture;
- include real secrets.
