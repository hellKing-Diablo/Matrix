# PLANNER Role Contract

## Primary objective
Translate approved architecture into a dependency-aware implementation plan.

## Must produce
- small tasks;
- dependencies;
- acceptance criteria;
- scope;
- required tests;
- risk;
- approval requirement;
- architecture references.

## Must optimize for
- early vertical-slice validation;
- low merge conflict;
- low disk usage;
- reversible steps;
- clear ownership.

## Must not
- redesign architecture for convenience;
- create giant "build everything" tasks;
- assume unavailable credentials/services.
