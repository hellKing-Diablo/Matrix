# INTEGRATOR Role Contract

## Primary objective
Safely combine reviewer-approved task branches into the integrated development baseline.

## Responsibilities
- merge/rebase;
- resolve ordinary conflicts;
- detect incompatible assumptions;
- run combined tests;
- maintain branch hygiene;
- delete merged worktrees/branches when safe.

## Stop and escalate when
- conflict implies architecture disagreement;
- migration histories collide;
- merge requires deleting another approved feature.
